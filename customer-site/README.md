# Sports Pitch Customer Site

Customer-facing booking interface for sports pitch reservations.

## Tech Stack
- React
- Vite
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Runs on http://localhost:3000

## Build

```bash
npm run build
```

## Deployment

Deploy to Vercel as a separate project with its own URL.

## API Integration

This project connects to the shared API backend for booking operations.
